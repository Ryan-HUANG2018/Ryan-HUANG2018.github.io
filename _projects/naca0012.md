## Setup

| Item                 | Value                                                |
| -------------------- | ---------------------------------------------------- |
| Reynolds number      | 1000                                                 |
| Flapping frequency   | 0.5 (non-dimensional)                                |
| Computational domain | 25*c* × 20*c* (_c_: chord length)                    |
| Grid spacing         | 0.005*c* (finest) to 0.04*c* (coarsest)              |
| Grid nodes           | 1,340,701                                            |
| Solver               | Multi-block IB–LBM fluid–structure interaction code  |
| Run time             | 35 minutes for 10 flapping cycles, 18 OpenMP threads |

The boxes in the animation are the boundaries of the grid blocks.
